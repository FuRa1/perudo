# Бриф по графике: генерация 2D-ассетов для игры «Перудо: Пираты Карибского моря»

## ВАЖНО ПРОЧИТАТЬ ПЕРВЫМ — что это за документ и что такое Scenario

**Scenario — это отдельный веб-сервис для рисования картинок (генератор изображений). Он НЕ связан с твоим проектом, НЕ трогает папки с кодом, НЕ знает про репозиторий.** Ты работаешь в нём через браузер как в обычном онлайн-редакторе: загружаешь примеры → обучаешь стиль → генерируешь картинки → **скачиваешь готовые PNG себе на компьютер**. Всё.

Этот документ разделён на две независимые части, которые происходят в разное время и делаются разными «исполнителями»:

- **ЧАСТЬ А — что делаешь ТЫ РУКАМИ в Scenario.** Обучение стиля и генерация картинок. Никаких путей к файлам и папок проекта здесь нет — только клики в веб-интерфейсе Scenario и промпты, которые копируешь в поле генерации.
- **ЧАСТЬ Б — что потом делает АГЕНТ (Claude Code) с уже готовыми картинками.** Здесь появляются пути в проекте (`/client/assets/...`). Это НЕ инструкция для Scenario и НЕ то, что ты вводишь куда-то руками — это для агента, на этапе Фазы 4 сборки приложения.

Если ты запутался «куда вставлять эти промпты» — ответ: **в поле генерации в Scenario (Часть А, Шаг 3), и больше никуда.** Промпты не идут в проект, не идут агенту, не идут в код. Они идут в Scenario, чтобы он нарисовал картинку.

# ЧАСТЬ А — РАБОТА РУКАМИ В SCENARIO (генерация картинок)

Цель части А: получить набор готовых PNG-картинок в едином пиратском стиле, скачанных на твой компьютер.

## Шаг 1. Подготовить референсы (art bible)
Собери 10–15 картинок-примеров в том стиле, который хочешь получить. Это не финальные ассеты, а «образцы вкуса» — по ним Scenario выучит стиль. Требования:
- разрешение не ниже 1024×1024 (Scenario умеет обрезать/апскейлить при загрузке);
- все примеры должны быть в ОДНОМ визуальном стиле (не мешай мультяшное с реализмом — разнобой «отравляет» датасет и портит результат);
- не добавляй картинки не в целевом стиле.

**Какой стиль искать (описание для подбора референсов):**
- плоская 2D-иллюстрация с лёгкой текстурной зернистостью (ощущение состаренной бумаги/дерева), мягкие контуры, тёплая палитра;
- палитра: тёмное дерево, состаренный пергамент, тёмно-синий/бирюзовый (море), золото/латунь (монеты, акценты), приглушённый красный (сургуч, флаги);
- вдохновение для поиска (НЕ для копирования — только направление): концепт-арт настольных пиратских игр, обложки книг про пиратов в стиле гравюры/акварели, «premium casual» мобильные игры с пиратской темой;
- избегай: мультяшного «детского» стиля, фотореализма, пиксель-арта.

## Шаг 2. Обучить стиль-модель (Train)
1. В Scenario открой раздел **Train** → тип **Style Model** (стилевая модель — самый простой тип).
2. Загрузи свои референсы перетаскиванием.
3. Scenario автоматически подпишет картинки (captions) — бегло просмотри, при желании поправь.
4. (Необязательно) добавь до 4 тестовых промптов, чтобы видеть качество по ходу обучения.
5. Запусти обучение. Займёт ~30 минут – пара часов; придёт уведомление о готовности.

## Шаг 3. Генерировать ассеты по обученному стилю (Generate)
1. Открой **Generate**, выбери **свою обученную модель** (не стоковую).
2. **Вот сюда вставляешь промпты из раздела ниже** — по одному в поле промпта, жмёшь Generate.
3. Поскольку стиль уже «зашит» в модель, в промптах описывается только ЧТО нарисовать; стиль применится сам.
4. Сравни результаты с референсами; если стиль «уплывает» — вернись к Шагу 2 (поправь датасет/подписи, переобучи).

## Шаг 4. Скачать результаты
Понравившиеся картинки скачай как **PNG (с прозрачным фоном, где применимо)** себе на компьютер. На этом работа в Scenario закончена.

## Промпты для генерации (копировать в поле Generate, Шаг 3)

> Каждый блок — отдельная генерация. Стиль уже в модели, поэтому промпты описывают только объект. При необходимости добавляй в конце `no background` и `centered`.

### Грани костей (6 штук)
Базовый промпт (меняй только число точек):
```
Flat 2D die face icon, aged bone/ivory texture with subtle weathering,
[N] engraved dots in classic dice pattern, warm sepia and cream tones,
soft edge shadow, no background, centered
```
Для «шестёрки» — пять точек + маленький череп вместо шестой:
```
Flat 2D die face icon, aged bone/ivory texture, five engraved dots plus
one small stylized skull replacing the sixth dot, classic six-pattern
layout, warm sepia and cream tones, no background, centered
```

### Фоновые текстуры
```
Seamless tileable texture, weathered dark wood planks, subtle grain and
scratches, warm brown tones, top-down, flat lighting, no objects
```
```
Aged parchment paper texture, subtle stains and burnt edges, cream and
tan tones, near-seamless, UI panel background, no text
```
```
Old nautical map texture, faded ink coastlines without readable text,
sepia tones, torn edges, UI panel background
```

### Иконки действий
Каркас (меняй только `[ОПИСАНИЕ]`):
```
Flat 2D icon, pirate game UI element, [ОПИСАНИЕ], warm gold and dark
wood palette, thick clean outline, readable at small size, no
background, centered
```
Варианты `[ОПИСАНИЕ]`:
- `raised fist gripping a coin — placing a bid`
- `crossed bones over a skull with a red X — calling a bluff`
- `hourglass with sand — turn timer`
- `small open treasure chest with golden glow — bonus/extra time`
- `checkmark shaped like a curved cutlass — ready/confirm`

### UI-рамки и декор
```
Flat 2D UI frame border, ornate wooden panel with rope trim, weathered
brass corner rivets, transparent center for content, warm brown and gold
```
```
Flat 2D button shaped like a wax-sealed scroll, cream parchment with red
wax seal, no text, empty for label overlay
```
```
Flat 2D ship's wheel icon, simplified silhouette, dark wood and brass,
usable as loading spinner or menu icon
```

# ЧАСТЬ Б — ЧТО ПОТОМ ДЕЛАЕТ АГЕНТ (не ты, не Scenario)

Это происходит уже в проекте, в **Фазе 4** сборки приложения (см. `CLAUDE.md`). Ты просто передаёшь агенту скачанные PNG, и он:
1. Кладёт файлы в папку ассетов проекта (например `/client/assets/dice/`, `/client/assets/textures/`, `/client/assets/icons/` — конкретную структуру определит агент).
2. Подключает грани костей через **конфигурируемую структуру костей** (данные, не хардкод — см. `CLAUDE.md`, раздел 8.2 и 3.5), чтобы визуал можно было заменить без правок логики.
3. Встраивает текстуры/иконки/рамки в вёрстку (Ionic + Tailwind) согласно пиратской теме.

**Агент картинки НЕ генерирует и НЕ рисует** — он только встраивает готовые файлы, которые пришли из Scenario. Генерация — исключительно Часть А (твоя ручная работа в Scenario).
