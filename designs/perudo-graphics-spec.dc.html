Always ask for
Matte painted texture · rounded silhouettes · one warm light source · generous empty space · desaturated mid-tones so UI text reads on top · flat-on or shallow three-quarter angle, never dramatic perspective.
Negative prompt
casino, chips, felt green, neon, glossy plastic, chrome, lens flare, HDR, photorealistic skin, text, numbers, letters, watermark, logo, UI frames, drop shadows baked in, high contrast black.

Lowercase, hyphenated, no spaces. Scale suffix only above @1x: die-face-3@2x.png.
Format rules
PNG-24 with alpha for anything that overlaps the table — dice, tokens, badges, avatars. JPG q86 for full-bleed backgrounds with no transparency (plus a WebP sibling). SVG only for flat vector marks: the app wordmark, the palifico banner ribbon, connection glyph. No baked drop shadows — the UI adds elevation. Trim to content, then pad roughly 6% transparent margin so glow does not clip — this applies to both dice cups too. No asset carries a baked drop shadow: the UI applies its own CSS elevation. Every raster arrives at @3x and downsamples; nothing is upscaled.
