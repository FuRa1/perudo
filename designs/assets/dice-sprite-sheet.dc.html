assets/dice/dice-sprite.css
.dice { width: 52px; height: 52px; background-image: url(dice-sprite.png); background-repeat: no-repeat; background-size: 312px 52px; background-position: 0 0; } .dice[data-face="2"] { background-position-x: -52px; } .dice[data-face="3"] { background-position-x: -104px; } .dice[data-face="4"] { background-position-x: -156px; } .dice[data-face="5"] { background-position-x: -208px; } .dice[data-face="6"] { background-position-x: -260px; } @keyframes dice-roll { from { background-position-x: 0px; } to { background-position-x: -312px; } } .dice.is-rolling { animation: dice-roll 480ms steps(6, end) infinite; }
Notes
Value changes touch nothing but background-position-x — markup is one empty <span class="dice" data-face="4">.
background-size is pinned to 312×52 so a scaled or retina context can never drift the frame window. The @2x source swaps the image only, at the same background-size.
steps(6, end) is what keeps the roll seam-free: the position only ever lands on exact frame edges, never between two faces.
